# Snake Game on FPGA (Kintex-7)

基于 Verilog 在 Kintex-7 FPGA 上实现的经典贪吃蛇游戏。

## 项目结构

```
snake/
├── rtl/                    # RTL 设计源码
│   ├── snake_top.v         # 顶层模块
│   ├── vga_controller.v    # VGA 时序控制器 (640×480 @ 60Hz)
│   ├── snake_game.v        # 贪吃蛇游戏核心逻辑
│   ├── snake_render.v      # VGA 图像渲染器
│   ├── clk_div.v           # 时钟分频 / 使能信号生成
│   ├── debounce.v          # 按键消抖模块
│   ├── lfsr.v              # LFSR 伪随机数生成器
│   ├── ps2_keyboard.v      # PS/2 键盘控制器 (新增)
│   └── seven_seg_display.v # 7段数码管驱动 (含扫描时序)
├── sim/
│   └── snake_tb.v          # 仿真测试平台 (支持 defparam 加速)
├── constraints/
│   └── snake_k7.xdc        # Kintex-7 引脚约束
└── README.md
```

## 功能特性

- **VGA 显示**: 640×480 @ 60Hz，4:4:4 RGB 色深
- **开始界面**: 标题 `SNAKE!`、难度选择、分难度历史最高分、标题周围旋转小蛇
- **游戏网格**: 40 列 × 30 行，每格 16×16 像素
- **蛇的控制**: 实体按键 + **PS/2 键盘双模式**，按键消抖（按键需按住 ≥16ms）
- **得分显示**: VGA 游戏画面左上角 + 4 位数码管实时显示 BCD 分数 (0-9999)
- **LED 指示**: 8 个 LED 显示游戏状态（见下方）
- **历史记录**: Easy / Normal / Hard 三档分别保存本次上电后的最高分

## 控制方式

### 实体按键

| 按键   | 引脚 | 功能       | 备注 |
|--------|------|------------|------|
| BTN[0] | W14  | 向上移动   | 低电平有效，内部上拉 |
| BTN[1] | V14  | 向下移动   | 低电平有效，内部上拉 |
| BTN[2] | V19  | 向左移动   | 低电平有效，内部上拉 |
| BTN[3] | V18  | 向右移动   | 低电平有效，内部上拉 |
| BTNX4  | W16  | 开始/选择当前菜单项 | 低电平有效，内部上拉 |
| rstn   | W13  | 外部复位   | 低电平有效，内部上拉 |

> **重要**: K7 按键是**低电平有效**（按下 = GND = 0）。RTL 内部通过 `~BTN[i]` 翻转后送入消抖模块。**按键需按住 ≥16ms** 才能被消抖模块识别。

### PS/2 键盘（推荐）

| 键盘按键 | 功能 | 替代键 |
|---------|------|--------|
| **↑** 方向键上 | 向上移动 | **W** |
| **↓** 方向键下 | 向下移动 | **S** |
| **←** 方向键左 | 向左移动 | **A** |
| **→** 方向键右 | 向右移动 | **D** |
| **Enter** | 开始/选择当前菜单项 | **Space** |
| **Esc** | 游戏中打开/关闭暂停菜单 | Restart / Cancel / Exit |

| 键盘引脚 | FPGA 引脚 |
|---------|----------|
| ps2_clk | N18 |
| ps2_data | M19 |

> **设计要点**: 键盘和实体按键的信号用 OR 合并，两种方式可以同时使用、互不冲突。

## 游戏规则

1. 上电进入开始界面，默认难度为 Normal
2. 在开始界面按左/上切到更低难度，按右/下切到更高难度，按 BTNX4 / Enter / Space 开始
3. 蛇初始长度 3，位于网格中央 (行15, 列18-20)，向右移动
4. 方向键控制蛇的移动（**不能 180° 掉头**，反向输入会被忽略）
5. 吃到红色食物：得分 +1，蛇身变长 1 节
6. 撞墙或撞到自己：**游戏结束 (GAME OVER)**，记录当前难度最高分，约 2 秒后回到开始界面
7. 游戏中按 **Esc** 打开暂停菜单，选择 Restart 直接重开，Cancel 返回游戏，Exit 退回开始界面

## 难度

| 难度 | 速度 | 说明 |
|------|------|------|
| Easy | 基础 tick / 4 | 最慢，适合调试和熟悉键位 |
| Normal | 基础 tick / 2 | 默认难度 |
| Hard | 基础 tick | 最快 |

## 时钟架构

| 信号 | 频率 | 来源 | 用途 |
|------|------|------|------|
| `clk` | 100MHz | 板载晶振 | 系统主时钟 |
| `vga_ce` | 25MHz (使能脉冲) | clk_div: ÷4 | VGA 像素时序 |
| `game_tick` | ~5Hz (使能脉冲) | clk_div: ÷20M | 游戏逻辑更新 |
| 数码管扫描 | ~763Hz | seven_seg_display 内部 | 4位数码管动态扫描 |
| 消抖采样 | ~1kHz | debounce 内部 | 按键消抖 16ms |

> **设计要点**: 全局使用 100MHz 单一时钟域，低频信号用**时钟使能脉冲**而非门控时钟，避免跨时钟域问题。

## 使用方法 (Vivado)

1. 创建 Vivado 工程，选择目标 Kintex-7 器件
2. 添加 `rtl/` 目录下所有 `.v` 源文件
3. 添加 `constraints/snake_k7.xdc` 约束文件
4. 运行综合 (Synthesis) → 实现 (Implementation) → 生成比特流
5. 下载到 FPGA

## 仿真

测试平台使用 `defparam` 覆盖硬件参数来加速仿真：

| 参数 | 硬件值 | 仿真值 | 加速比 |
|------|--------|--------|--------|
| GAME_TICK_DIV | 19,999,999 (200ms) | 99 (1µs) | ×200,000 |
| DEAD_TIME | 199,999,999 (2s) | 999 (10µs) | ×200,000 |

```bash
# Vivado XSim
# 将 snake_tb.v 设为仿真顶层 → Run Behavioral Simulation

# 或使用 iverilog
iverilog -o snake_tb rtl/*.v sim/snake_tb.v
vvp snake_tb
gtkwave snake_tb.vcd
```

仿真日志会输出方向切换、游戏结束等关键事件。

## 硬件调试

如果方向控制在硬件上不工作，按下列步骤排查：

1. **检查 LED[2] 心跳灯** — 不闪烁说明时钟有问题
2. **检查 LED[0] 是否亮** — 不亮说明蛇可能在复位状态
3. **确认板卡型号与引脚匹配** — 不同 K7 板卡的按键引脚可能不同，需核对原理图修改 `snake_k7.xdc`
4. **按键至少按住 16ms** — 消抖模块需要 16 个连续采样周期，轻触可能不被识别
5. **用示波器测按键引脚** — 按下时应为 0V (GND)，松开应为高电平 (PULLUP)
