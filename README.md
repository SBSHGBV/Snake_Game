# Snake Game on FPGA (Kintex-7)

基于 Verilog 在 Kintex-7 FPGA 上实现的经典贪吃蛇游戏。

## 项目结构

```
snake/
├── rtl/                    # RTL 设计源码
│   ├── snake_top.v         # 顶层模块
│   ├── vga_controller.v    # VGA 时序控制器 (640×480 @ 60Hz)
│   ├── snake_game.v        # 贪吃蛇游戏核心逻辑
│   ├── snake_render.v      # VGA 图像渲染器
│   ├── clk_div.v           # 时钟分频 / 使能信号生成
│   ├── debounce.v          # 按键消抖模块
│   ├── lfsr.v              # LFSR 伪随机数生成器
│   ├── ps2_keyboard.v      # PS/2 键盘控制器
│   └── seven_seg_display.v # 7段数码管驱动 (含扫描时序)
├── sim/
│   └── snake_tb.v          # 仿真测试平台 (支持 defparam 加速)
├── constraints/
│   └── snake_k7.xdc        # Kintex-7 引脚约束
└── README.md
```

## 功能特性

- **VGA 显示**: 640×480 @ 60Hz，4:4:4 RGB 色深，丰富的配色方案
- **开始界面**: 标题 `SNAKE!` 大字、环绕装饰动画蛇（沿轨道游动，蛇头蓝色+蛇身绿色）、难度选择器（左右箭头切换 EASY/NORM/HARD）、当前难度历史最高分、三档难度历史记录一览、闪烁 "START" 提示
- **暂停菜单**: 游戏中按 Esc 呼出，`PAUSE` 标题 + 三项操作（RESTART 重新开始 / CANCEL 返回游戏 / EXIT 退回主菜单），选中项有边框高亮和颜色变化
- **死亡画面**: 撞墙或自碰后显示 `GAME OVER` 和最终 `SCORE`，按确认键返回主菜单
- **游戏网格**: 40 列 × 30 行，每格 16×16 像素
- **蛇的控制**: 实体按键 + **PS/2 键盘双模式**，按键消抖（按键需按住 ≥16ms）
- **蛇头/蛇身区分**: 蛇头蓝色、蛇身绿色，便于判断方向
- **得分显示**: VGA 游戏画面左上角实时 HUD + 4 位数码管实时显示 BCD 分数 (0-9999)
- **LED 指示**: 8 个 LED 显示游戏状态和难度档位（见下方）
- **历史记录**: Easy / Normal / Hard 三档分别保存本次上电后的最高分

## 控制方式

### 实体按键

| 按键   | 引脚 | 功能       | 备注 |
|--------|------|------------|------|
| BTN[0] | W14  | 向上移动   | 低电平有效，内部上拉 |
| BTN[1] | V14  | 向下移动   | 低电平有效，内部上拉 |
| BTN[2] | V19  | 向左移动   | 低电平有效，内部上拉 |
| BTN[3] | V18  | 向右移动   | 低电平有效，内部上拉 |
| BTNX4  | W16  | 开始/选择当前菜单项 | 低电平有效，内部上拉 |
| rstn   | W13  | 外部复位   | 低电平有效，内部上拉 |

> **重要**: K7 按键是**低电平有效**（按下 = GND = 0）。RTL 内部通过 `~BTN[i]` 翻转后送入消抖模块。**按键需按住 ≥16ms** 才能被消抖模块识别。

### PS/2 键盘（推荐）

| 键盘按键 | 功能 | 替代键 |
|---------|------|--------|
| **↑** 方向键上 | 向上移动 | **W** |
| **↓** 方向键下 | 向下移动 | **S** |
| **←** 方向键左 | 向左移动 | **A** |
| **→** 方向键右 | 向右移动 | **D** |
| **Enter** | 开始/选择当前菜单项 | **Space** |
| **Esc** | 游戏中打开/关闭暂停菜单 | Restart / Cancel / Exit |

| 键盘引脚 | FPGA 引脚 |
|---------|----------|
| ps2_clk | N18 |
| ps2_data | M19 |

> **设计要点**: 键盘和实体按键的信号用 OR 合并，两种方式可以同时使用、互不冲突。

## 游戏流程

### 状态机

```
         ┌────────┐  btn_start    ┌──────────┐
 上电 ──→│  MENU  │──────────────→│ PLAYING  │
         │(开始界面)│              │ (游戏中)  │
         └────────┘              └──────────┘
              ↑                      │  │  │
              │      collision       │  │  │ Esc (pause_sig)
              │ ┌────────────────────┘  │  │
              │ │  btn_start            │  │
              │ ▼                      │  ▼
         ┌────────┐                    │ ┌─────────┐
         │  DEAD  │←────────────────────┘ │ PAUSE   │
         │(死亡画面)│                     │(暂停菜单)│
         └────────┘                     └─────────┘
              ↑                              │
              │  Exit (选中EXIT+btn_start)   │
              └──────────────────────────────┘
              │  Restart (选中RESTART+btn_start)
              │  Cancel  (选中CANCEL+btn_start 或按Esc)
              └──────────────────────────────→ PLAYING
```

### 详细规则

1. 上电进入**开始界面 (MENU)**，默认难度为 Normal
2. 在菜单界面按**左/上**切到更低难度，按**右/下**切到更高难度：
   - `EASY` — 蛇移动速度 = 基础 tick / 4（最慢）
   - `NORM` — 蛇移动速度 = 基础 tick / 2（默认）
   - `HARD` — 蛇移动速度 = 基础 tick（最快）
3. 按 **BTNX4 / Enter / Space** 开始游戏
4. 蛇初始长度 3，位于网格中央 (行15, 列18-20)，初始方向向右
5. 方向键控制蛇的移动（**不能 180° 掉头**，反向输入会被忽略，包括快速连续按键也不会绕过检测）
6. 吃到红色食物：得分 +1，蛇身变长 1 节；食物会立即在随机空白位置重新生成
7. 撞墙或撞到自己：**游戏结束 (GAME OVER)**，自动记录当前难度最高分，显示最终分数，按 **BTNX4 / Enter / Space** 确认后返回菜单
8. 游戏中按 **Esc** 打开**暂停菜单**：
   - `RESTART` — 直接重新开始当前难度（保留难度设置）
   - `CANCEL` — 关闭菜单，返回游戏
   - `EXIT` — 退回主菜单（同时记录最高分）
   - 按**上/下 或 左/右**切换选项，按 **Start/Enter** 确认，按 **Esc** 等同于 CANCEL

## 难度系统

| 难度 | 编码 | 速度（相对基础 tick ~5Hz） | 有效移动频率 | 说明 |
|------|------|--------------------------|-------------|------|
| Easy | 2'd0 | ÷4 | ~1.25 Hz | 最慢，适合新手和调试 |
| Normal | 2'd1 | ÷2 | ~2.5 Hz | 默认难度，适中节奏 |
| Hard | 2'd2 | ×1 | ~5 Hz | 最快，挑战模式 |

> **实现**: 使用 `move_div_cnt` 计数器实现分数分频，不引入额外时钟域。`move_div_limit` 由 `difficulty_reg` 查表决定。

### 分难度最高分

- 三个难度各有**独立的历史最高分寄存器**（`high_easy_reg` / `high_normal_reg` / `high_hard_reg`）
- 游戏结束或退出到菜单时自动比较并更新
- 主菜单同时显示三档难度的历史记录，当前选中的难度最高分会特殊高亮
- 断电后重置（由 FPGA 上电复位初始化）

## 时钟架构

| 信号 | 频率 | 来源 | 用途 |
|------|------|------|------|
| `clk` | 100MHz | 板载晶振 | 系统主时钟 |
| `vga_ce` | 25MHz (使能脉冲) | clk_div: ÷4 | VGA 像素时序 |
| `game_tick` | ~5Hz (使能脉冲) | clk_div: ÷20M | 游戏逻辑更新 |
| 数码管扫描 | ~763Hz | seven_seg_display 内部 | 4位数码管动态扫描 |
| 消抖采样 | ~1kHz | debounce 内部 | 按键消抖 16ms |

> **设计要点**: 全局使用 100MHz 单一时钟域，低频信号用**时钟使能脉冲**而非门控时钟，避免跨时钟域问题。

## 使用方法 (Vivado)

1. 创建 Vivado 工程，选择目标 Kintex-7 器件
2. 添加 `rtl/` 目录下所有 `.v` 源文件
3. 添加 `constraints/snake_k7.xdc` 约束文件
4. 运行综合 (Synthesis) → 实现 (Implementation) → 生成比特流
5. 下载到 FPGA

## 仿真

测试平台使用 `defparam` 覆盖硬件参数来加速游戏 tick 仿真：

| 参数 | 硬件值 | 仿真值 | 加速比 |
|------|--------|--------|--------|
| GAME_TICK_DIV | 19,999,999 (200ms) | 99 (1µs) | ×200,000 |

```bash
# Vivado XSim
# 将 snake_tb.v 设为仿真顶层 → Run Behavioral Simulation

# 或使用 iverilog
iverilog -o snake_tb rtl/*.v sim/snake_tb.v
vvp snake_tb
gtkwave snake_tb.vcd
```

仿真日志会输出方向切换、游戏结束等关键事件。

## 硬件调试

如果方向控制在硬件上不工作，按下列步骤排查：

1. **检查 LED[2] 心跳灯** — 不闪烁说明时钟有问题
2. **检查 LED[0] 是否亮** — 不亮说明蛇可能在复位状态
3. **确认板卡型号与引脚匹配** — 不同 K7 板卡的按键引脚可能不同，需核对原理图修改 `snake_k7.xdc`
4. **按键至少按住 16ms** — 消抖模块需要 16 个连续采样周期，轻触可能不被识别
5. **用示波器测按键引脚** — 按下时应为 0V (GND)，松开应为高电平 (PULLUP)

### 2026-07-02 — 完整功能版 (my 分支)

**新增功能：**
- **三档难度系统**：Easy / Normal / Hard，通过 `move_div_cnt` 分数分频实现不同移动速度
- **分难度最高分**：三档各有独立寄存器，游戏结束/退出时自动比较更新
- **完整暂停菜单**：PAUSE 标题 + RESTART / CANCEL / EXIT 三项，选中项边框高亮+颜色区分
- **确认式死亡画面**：GAME OVER + 最终 SCORE，按确认键后回到主菜单
- **环绕装饰动画蛇**：主菜单标题周围沿矩形轨道游动，头蓝身绿，与游戏蛇同款 16×16 格点样式
- **蛇头/蛇身颜色区分**：蛇头蓝色 (4,8,15)，蛇身绿色 (4,15,0)，便于判断方向
- **游戏内 HUD**：左上角实时 SCORE + 4 位 BCD 分数
- **丰富配色**：菜单各区域 7 种专用颜色，暂停菜单选中/未选中对比色

**修复/优化：**
- 修复蛇头进入旧尾格时尾格被错误清零（衔尾问题）
- PS/2 `Esc` 改为暂停菜单，移除 `R` 键重启
- PS/2 帧接收时序修复（stop bit 当拍完成并输出）
- 菜单文字布局使用 32/64 像素对齐网格，减少组合逻辑复杂度
- 食物生成碰撞检测：LFSR 候选位置与蛇身重叠时自动重试下一周期
- `self_collision` 边界保护：坐标下溢时防止越界读 grid_reg
- `food_eaten` 加 `food_valid` 条件判断
- 蛇长上限 256 (MAX_LEN)，分数上限 9999 (BCD)
- 方向控制使用已提交方向判定合法性，保留移动前最后一个有效输入，防止连续两次 90° 转向排入反向方向
- 标题小蛇速度跟随当前选择难度，并修复轨道左上角闭环断裂导致身体消失的问题
- 死亡后不再自动回主菜单，改为显示最终分数并等待确认

**代码质量：**
- `GAME_TICK_DIV` 参数化，支持仿真 defparam 覆盖
- `por_cnt` 加初始值适配仿真
- 仿真加速比 ×200,000（game_tick: 200ms→1µs, dead_time: 2s→10µs）
- LFSR Galois 多项式 x¹⁶+x¹⁵+x¹³+x⁴+1 验证正确
- 消抖模块初始值 0xFFFF 防止上电误触发
